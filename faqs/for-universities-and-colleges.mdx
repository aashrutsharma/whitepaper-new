<AccordionGroup>
  <Accordion title="What do we receive, and when?" icon="file-check">
    The instant a student's payment clears, a record arrives. It has the verified identity and category, the programme and round, the document status with a reference to each document, and proof that payment has cleared.
  </Accordion>
  <Accordion title="Do we get the actual documents?" icon="files">
    You get a reference to each verified document. The raw files are not sent unless your college needs them.
  </Accordion>
  <Accordion title="What happens on reporting day?" icon="building-2">
    The student comes in person with originals. You scan a single-use code. Three checks run instantly: payment cleared, allotment still valid, and no duplicate admission elsewhere.
  </Accordion>
  <Accordion title="What if a check fails?" icon="triangle-alert">
    The student is not turned away automatically. It is flagged for a staff member, who sees exactly what to verify by hand.
  </Accordion>
  <Accordion title="What if a seat goes unclaimed?" icon="refresh-cw">
    If the reporting window closes and a seat was never confirmed, it is reported back into the system automatically. That feeds the next round or a spot round.
  </Accordion>
  <Accordion title="Do we need to change our systems?" icon="database">
    No. Your internal records, fee collection, academic processes and reporting to your university, board or regulator stay as they are.
  </Accordion>
  <Accordion title="How do we connect?" icon="plug">
    Two ways. A simple web view with no integration, or an API that sends confirmed allotments straight into your own student database. You can start with the web view and move to the API later.
  </Accordion>
  <Accordion title="Will we have to trust Verified by Superadmission?" icon="shield-check">
    Time is saved only if a college is willing to rely on it instead of re-checking. That cannot be assumed. In some cases it may need regulatory confirmation. It has to be shown, probably starting with colleges that already work digitally.
  </Accordion>
  <Accordion title="Can colleges appear in Manifest?" icon="database">
    Manifest is a registry of every degree-granting institution. It does not charge institutions to be listed or ranked, and no institution can pay to change how it appears. A blank field only means a fact has not been verified yet. See [Manifest](/superadmission/manifest).
  </Accordion>
</AccordionGroup>
